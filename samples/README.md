## 导入顺序

1. 在目标测试项目打开「项目资料」，将 01、02、03 分别提交为新资料。负责人在各份资料详情中审核，批准后等待索引显示「已就绪」。索引需要可用的向量服务。
2. 负责人打开「项目管理 → 验收依据」，选择标书 V1 和技术规范 V1，整套发布为「首轮验收」。Robot 关键字说明作为编写草稿时的参考资料。
3. 要测版本切换时，打开原「抄读技术规范」，点「提交新版本」，上传 04 并填 V2。审核且就绪后，选择标书 V1 和技术规范 V2，发布「第二轮验收」。

## 三个可以直接问的问题

| 在聊天框发送                                                                           | 核对回答                                                                                                                                                                         |
| -------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 访客抄表被拒绝时，响应里可以出现电量吗？怎样用日志证明拒绝原因？请引用原文。           | 应引用标书 ZB-02、技术规范 T-19。返回 DENIED 和请求编号，响应中没有电量；按同一请求编号核对日志中的角色和拒绝原因 NO_READ_PERMISSION。                                           |
| 我写的用例只检查访客收到 DENIED。请按标书指出漏测项，使用项目关键字补一份 Robot 草稿。 | 应补充检查响应无电量、审计与请求编号一致、原因正确。可采用「模拟抄读」「读取审计记录」，模拟库的实际导入名称应列为待确认。                                                       |
| 假设授权抄读耗时 2.5 秒，请分别按技术规范 V1 和 V2 判断，并给出对应原文。              | 两个版本均已就绪后，查 V1 的 T-17 为 3 秒，查 V2 的 T-17 为 2 秒，分别得到达标、未达标。此处的 2.5 秒是题设值。需要核对真实运行时，在「运行记录」另行登记 Robot 结果和测量日志。 |
