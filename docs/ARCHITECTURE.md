# 工作台架构

浏览器通过 Nginx 访问 Vue 静态文件、Java 业务 API 及 SSE 回答流。Java 持有用户、项目和授权事实。Python 通过短期委托读取本轮允许的文件，调用向量模型、Qdrant 与聊天模型。项目成员的浏览器与模型服务之间没有直接网络请求。

| 组件            | 负责的内容                                                                                           |
| --------------- | ---------------------------------------------------------------------------------------------------- |
| Vue             | 登录、个人对话与来源、项目资料、运行、成员及平台管理                                                 |
| Java / MySQL    | 项目、角色、文档读者、版本审批、验收包、原始运行、会话、幂等与审计                                   |
| Redis           | 登录尝试计数及窗口过期                                                                               |
| Python / Qdrant | 文档分块、向量索引、授权范围内的检索、Robot XML 静态解析、回答与草稿                                 |
| 持久卷          | Java 保存原件，Python 保存索引作业状态。MySQL 和 Qdrant 保存各自的数据。独立身份卷保存服务签名材料。 |

负责人审核原件后才创建索引任务，Java 校验解析结果再发布可引用版本。回答过程中由 Java 校验引用范围、运行事实与正文位置。个人附件和会话以项目及本人为授权边界。技术细节见[领域模型](DOMAIN_MODEL.md)、[契约](contracts/README.md)及[容器运行](development/CONTAINERS.md)。
