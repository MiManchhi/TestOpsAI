## M1：Java 核心业务后端

状态：IN_PROGRESS；M1.1/M1.2 已有实现，历史本机验证见 CURRENT 链接；M1.3/M1.4 仍 PLANNED。后续工作按具体授权任务推进，不一次铺开全部业务。

1. **M1.1 数据基线**：核对 DATABASE/API，冻结首批用户/角色关系及约束；引入必要的 MySQL、持久化与迁移依赖，编写首批版本化迁移和真实 MySQL 集成测试。先验证数据库连通、约束、重复数据/失败路径，再实现认证。
2. **M1.2 身份与授权**：登录、密码散列、JWT/RBAC、401/403、资源级授权与测试；规范化错误和请求追踪。
3. **M1.3 业务元数据**：知识库、模拟测试用例的最小 API 与事务、分页、权限测试。
4. **M1.4 缓存与限流**：仅在真实业务路径上引入 Redis，明确失败策略、TTL 与测试，不把 Redis 当业务事实唯一来源。

M1 验收：无需 Vue 也能通过 API 完成身份与业务流程；真实数据库迁移、事务及越权路径有证据。具体接口和依赖兼容性在每项开始时核实，不在路线图里伪造未实现 schema。
