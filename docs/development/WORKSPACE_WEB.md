# Web 工作台开发与验收计划

本计划配合[产品蓝图](../PRODUCT_DESIGN.md)、[逐页操作表](../WEB_UI_DESIGN.md)、[接口契约](../contracts/workspace.openapi.json)和[三端联合验收](PARALLEL_DEVELOPMENT.md)使用。下表给出当前源码入口和对应的验收任务。已验证的范围由[本次交接](../../.memory/sessions/2026-11-20-07-workspace-cutover.md)记录。

## 按用户任务开发与验收

下列源码位置相对 `apps/web/src`。浏览器通过 `app/http.ts` 访问 Java；消息、读者权限、业务状态和版本号以服务端最新响应为准。

| 工作项                | 代码位置和实现顺序                                                                                                                                                                                                                                                | 交付时验证                                                                                                                                 |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| W1 登录与身份         | 在 `features/auth/session.ts` 处理 v1 登录、会话恢复与个人资料；`app/workspace-contracts.ts` 和各业务域 API 校验 v3 响应。账号被停用或重置后清除凭据。                                                                                                            | 测试首次改密、刷新、过期登录、空项目列表与多项目；验证缺少权限时的错误提示。                                                               |
| W2 项目入口           | 在 `app/router.ts` 和 `features/workspace/WorkspaceLayout.vue` 根据身份展示平台管理、项目导航或加入项目提示。切换项目时清除私有附件、消息流和来源抽屉。                                                                                                           | 管理员可在平台选择项目；成员可直接启动对话。验证深链接、返回、键盘和手机导航，以及同一用户在两项目的不同角色。                             |
| W3 账号、项目和人员   | `features/auth/PlatformAccountsPage.vue` 和 `PasswordPage.vue` 处理账号和改密。以 `features/projects/WorkspaceProjectsPage.vue` 管项目列表、创建；以 `WorkspaceProjectSettingsPage.vue`、`ProjectSettingsNav.vue` 管资料概要、成员与交接。通过各域 API 提交更改。 | 管理员创建账号并指定首位负责人；负责人添加、移除成员或更改角色。交接在管理员确认后生效。测试管理员代办、修改冲突和受限资料审核权限的转移。 |
| W4 项目资料与验收依据 | `features/knowledge/WorkspaceDocumentsPage.vue` 负责列表，`WorkspaceDocumentForm.vue` 提交文件及版本，`WorkspaceDocumentPage.vue` 负责原件、审核、读者及解析状态，`WorkspaceBasisPage.vue` 发布整套依据。`WorkspacePlatformJobsPage.vue` 为平台展示处理状态。     | 开发提交 → 负责人审核原件 → 索引就绪 → 授权成员按版本引用。另测退回原因、失败重试、新版继承读者、撤权后旧来源不可见，以及定时生效的版本。  |
| W5 运行登记与核对     | `features/runs/WorkspaceRunsPage.vue` 与 `workspace-runs.ts` 处理列表、登记、详细结果和原始日志。上传 output.xml，可附日志。本地输入执行时间后按 UTC 提交。登记操作保留幂等键。                                                                                   | 开发和测试分别登记；重复提交只出现一次。轮询解析状态，刷新可继续。从详情打开指定日志行，保留回原对话入口。                                 |
| W6 连续对话           | `features/assistant/WorkspaceChatPage.vue`、`workspace-chat.ts` 处理个人历史、附件、自动首问建会话和 SSE。历史随用户及项目隔离；仅服务器请求澄清时展示候选运行。模型未配置时展示实际依赖状态。                                                                    | 无手选上下文直接提问。首轮核对复测，第二轮要求生成回归用例。验证中文输入法、断线带 Last-Event-ID 重订、取消、切换会话及历史撤权。          |
| W7 证据与业务页面衔接 | 在聊天页按回答类型展示时间判定、待确认项和可复制 Robot 草稿，`SafeMarkdown.vue` 渲染正文；打开引用前请求 Java 核验。`features/workspace/chat-handoff.ts` 校验传入独立业务页的附件和会话标识。                                                                     | 分别打开当时与当前版本条款及日志行；撤权后再次打开、复制、刷新均遵守新授权。聊天转登记或提交资料完成后回原对话。                           |
| W8 三端与浏览器验收   | 使用日常启动命令部署 Web、Java、Python 及存储服务，依联合验收 J1–J7 逐项签收。                                                                                                                                                                                    | 分别记录平台管理员、负责人、测试、开发的操作，以及窄屏、键盘、重试和故障状态的实际结果。使用正式模型实测生成和引用质量。                   |

每次修改执行 `npm run check --workspace @testops/web` 和 `npm run contracts:check`。联调记录中给出页面、角色、请求操作、服务配置类型和结果；测试数据采用自造用例。

## 交互、动效与点击热区

| 场景               | 交互规则                                                                                                                                                                                                             | 验收动作                                                                                                             |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 主导航、表格、引用 | 可操作按钮、分页、头像、折叠/展开的最小命中区 44×44 CSS px；图标可小于热区。复选框整行 label 可点；名称打开详情，行尾操作是独立按钮。相邻操作保持间隔。                                                              | 在 390px 和桌面测 getBoundingClientRect，点标签边缘也生效，点编辑不触发行导航。窄屏表格在自己的容器滚动。            |
| 过渡与减少动态效果 | hover/按下/颜色反馈 120ms，抽屉入场 180ms，遮罩淡入。关闭后立即释放背景和焦点。prefers-reduced-motion: reduce 时移除位移与动画。更新数据保持原列表与滚动位置。                                                       | 点下立即见反馈；快速开关抽屉不残留遮罩；开启系统减少动画后检验计算样式和键盘操作。                                   |
| 表单、失败与重试   | 错误就近说明如何修复，首次失败聚焦首个无效字段，设置 aria-invalid/aria-describedby，修正后清除。提交中禁重复写，明确“正在保存”；失败保留安全输入。删除成员、重置密码、交接生效前列出对象与具体后果；取消为安全操作。 | 无鼠标提交空表单、后台超时、409 并发、停用后 401。含临时密码的表单仅留内存，成功或离开清除；表单错误持续显示至修正。 |
| 导航与键盘         | 路由切换聚焦标题，活动页 aria-current。对话框显示可读标题；打开后第一个操作获焦，Tab/Shift+Tab 在对话框循环，Esc、关闭、遮罩均恢复触发按钮；背景 inert。按钮用可访问名称，焦点轮廓与边界清晰。                       | 打开证据、查看出处、返回聊天；用键盘遍历资料审核和成员编辑。抽屉内打开来源时焦点应在目标页标题。                     |
| 聊天和移动端       | 空态直接输入，首问自动建会话并命名。Enter 发送，Shift+Enter 换行，composition 期间等待确认。窄屏历史放抽屉；输入区避开 safe-area 和软键盘，换行自增高后区内滚动。靠近底部才随新内容滚动，否则展示“回到最新”。        | 中文选词、粘贴多行代码、附文件后移除、发送中停止、键盘弹出后一屏可按发送。断线显示重连，无第二个用户气泡。           |
| 反馈和无障碍       | 待确认/未启动/就绪/失败同时具备文字。成功提示用 role=status，阻断错误在页面内保留；进度变化按阶段播报，避免逐字播报。登录、重放或授权失败及时清除受限内容。                                                          | 键盘、200% 缩放、减少动画、长项目名、长文件名、空列表、慢连接各跑一次；冲突可回查并重新提交，超时不能显示成功。      |

W8 在真实服务上以角色逐页签收。每个失败附路由、viewport、角色、操作、请求号与期望；记录使用的浏览器、真实服务和模型配置类型。
