# ADR-0010 · AI 工作台与权限边界

2026-11-19。状态：ACCEPTED，用户已确认六项规则与整体界面方向。此决策接替 ADR-0007 的产品规划。ADR-0008/0009 描述存量 v2 的实现，供迁移使用。

## 决策

工作台采用项目内知识与证据辅助判断，使用个人对话；用例由工程师粘贴/附文件，AI 返回可复制的 Robot 草稿。产品内的正式写入通过各自业务页。开发与测试都能登记运行，负责人审核资料、管理成员并指定验收依据。负责人发起交接，管理员确认或在原负责人离岗时代办并记录原因。资料先审原件，批准后进入 AI；全项目以一套多文件验收包同时生效。平台管理员创建项目与指定首位负责人，平台元数据权与项目内容权限独立。

## 设计影响

历史与当前依据都可核对。审核、索引、读者与验收依据分别建模；文档显示、检索、历史对话与旧引用在服务端重新授权。旧 v2 与目标的角色、项目创建、知识范围和草稿副作用不同。公共路径 v3、内部回答/证据 v2，保留 v1 登录和已实现内部解析/索引/对象协议。接入前处理旧读写旁路并回归。
