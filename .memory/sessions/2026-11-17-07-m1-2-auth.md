## 实施结果与验证（2026-11-17）

### 变更清单

- pom.xml：新增 jjwt-api/impl/jackson 0.12.6。
- application.yaml：增加 testopsai.jwt.secret/expiration-minutes 配置。
- V2 迁移：种子角色 ADMIN/USER + 演示管理员 admin（bcrypt 哈希占位）。
- V3 迁移：修正 admin 密码哈希为 admin123 的有效 bcrypt 值。
- V4 迁移：确保 admin 拥有 ADMIN 角色（V2 的 INSERT SELECT 因测试数据干扰未生效）。
- modules/identity/：AppUser、UserRepository、AuthService、AuthController、UserController、LoginRequest/LoginResponse/UserResponse。
- platform/security/：JwtProperties、JwtTokenProvider、JwtAuthenticationFilter、TestOpsUserDetailsService、SecurityExceptionHandler；SecurityConfiguration 重构。
- platform/error/：ErrorResponse/RequestIdFilter 改为 public（跨包访问）；GlobalExceptionHandler 增加 log.error。
- compose.yaml：server 服务新增 JWT_SECRET 环境变量（吸取 M1.1 教训，未误放到 mysql 服务）。
- .env.example / setup.ps1 / ci.yml：新增 JWT_SECRET 生成与传递。
- 集成测试：AuthIntegrationTest（5 项）、更新 BoundaryTest/ErrorContractTest 适配新安全配置。
- 文档：API.md（M1.2 接口）、DATABASE.md（V2-V4 迁移）、ADR-0004。

### 调试过程

- bcrypt hash 不匹配：V2 中的占位 hash 不是 admin123 的有效值；通过 Java BCryptPasswordEncoder 生成正确 hash 并创建 V3 迁移修正。
- user_roles 为空：V2 的 INSERT SELECT 因 M1.1 测试数据导致自增 id 偏移，SELECT 子查询在 Flyway 事务内未匹配到预期行；创建 V4 迁移用 INSERT IGNORE 补救。
- 容器登录测试 INTERNAL_ERROR：docker compose exec + curl stdin 的 shell 转义问题导致 JSON 解析失败；通过 Node.js HTTP 直接请求 nginx 代理验证代码正确性。
- compose.yaml JWT_SECRET 误放：替换逻辑匹配到 mysql 服务的 MYSQL_PASSWORD 行；手动修正为仅 server 服务。
- .env 缺少 JWT_SECRET：M0 setup.ps1 运行时还没有 JWT_SECRET；通过 Node.js 追加随机值。
